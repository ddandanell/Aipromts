Goal:
Analyze a problem and generate a structured solution plan for {{problem_statement}}

Steps:
1. Define the problem clearly (root cause analysis)
2. Identify constraints and success criteria
3. Generate 3–5 potential solutions
4. Evaluate solutions against constraints
5. Select and detail the recommended solution

Output:
- Problem definition
- Constraints
- Solution options (with pros/cons)
- Recommended solution
- Implementation steps
- Success metrics
